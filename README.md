# Modulo 1: Shorten Service

Este servicio se encarga de recibir una URL larga y generar un identificador corto, guardando la relación en DynamoDB.

## Requisitos
- Node.js 20+
- Terraform
- AWS CLI configurado

## Estructura
- `src/`: Código fuente en TypeScript.
- `terraform/`: Definiciones de infraestructura.

## Comandos
- `npm install`: Instalar dependencias.
- `npm run build`: Compilar TypeScript a JavaScript.
- `terraform init`: Inicializar Terraform.
- `terraform apply`: Desplegar infraestructura.
